# 陈记海鲜在线下单系统 — 部署文档

## 一、环境要求

- **Node.js** >= 18.x
- **npm** >= 9.x
- **操作系统**：Linux / macOS / Windows

## 二、项目结构

```
online_order/
├── client/                  # React 前端 (Vite + antd-mobile)
│   ├── src/                 # 源码
│   ├── dist/                # 构建产物（npm run build 后生成）
│   └── package.json
├── server/                  # Express 后端
│   ├── src/
│   │   ├── database/        # SQLite 数据库初始化 & 连接
│   │   ├── middleware/       # 认证中间件
│   │   ├── routes/           # API 路由
│   │   ├── utils/            # 工具函数
│   │   ├── app.js            # Express 应用
│   │   ├── config.js         # 配置（读取环境变量）
│   │   └── index.js          # 入口
│   ├── data/                 # SQLite 数据库文件（自动创建）
│   ├── .env                  # 环境变量（敏感配置）
│   └── package.json
├── uploads/                  # 上传文件目录
├── package.json              # 根 package（concurrently 启动）
└── docs/                     # 文档
```

## 三、快速部署（单机）

### 1. 上传项目到服务器

```bash
# 将整个项目目录上传到服务器
scp -r online_order/ user@server:/opt/
```

### 2. 安装依赖

```bash
cd /opt/online_order
npm install           # 根目录安装 concurrently
cd server && npm install && cd ..
cd client && npm install && cd ..
```

### 3. 配置环境变量

```bash
cp server/.env.example server/.env
# 编辑 server/.env，修改以下配置：
```

**server/.env 配置项：**

```env
# 必填
DEEPSEEK_API_KEY=sk-xxx           # DeepSeek API Key（AI 功能需要）
JWT_SECRET=your-random-secret     # JWT 签名密钥，生产环境请修改
ADMIN_PASSWORD=admin123           # 管理员初始密码，首次登录后修改

# 可选
PORT=3001                         # 服务端口
DEEPSEEK_MODEL=deepseek-chat      # AI 模型

# 微信支付（可选）
WXPAY_ENABLED=false
WXPAY_MCH_ID=
WXPAY_APP_ID=
WXPAY_APP_SECRET=
WXPAY_API_V3_KEY=
```

### 4. 构建前端

```bash
cd client && npm run build
# 产物在 client/dist/
```

### 5. 启动服务

**开发模式（前后端分离，支持热重载）：**
```bash
npm run dev
# 前端: http://localhost:5173
# 后端: http://localhost:3001
```

**生产模式（单端口）：**
```bash
NODE_ENV=production npm start
# 访问: http://localhost:3001
```

生产模式下，Express 直接托管 `client/dist/` 静态文件，前端和后端共用同一端口。

### 6. 使用 PM2 守护进程

```bash
npm install -g pm2

# 启动
cd /opt/online_order/server
NODE_ENV=production pm2 start src/index.js --name online-order

# 设置开机自启
pm2 startup
pm2 save
```

## 四、Nginx 反向代理（推荐）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    client_max_body_size 10M;

    location / {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /uploads/ {
        alias /opt/online_order/uploads/;
    }
}
```

## 五、数据备份

SQLite 数据库文件位于 `server/data/online_order.db`。

```bash
# 备份
cp server/data/online_order.db server/data/online_order.db.$(date +%Y%m%d)

# 定时备份（crontab）
0 2 * * * cp /opt/online_order/server/data/online_order.db /backup/online_order_$(date +\%Y\%m\%d).db
```

上传的商品图片位于 `uploads/` 目录，也建议一并备份。

---

## 六、初始化数据库

首次启动时系统自动创建表结构和默认数据：
- 默认管理员：`admin` / `admin123`
- 默认分类：蔬菜、肉类、海鲜、水果、豆制品、调料干货
- 默认时段：午餐（11:00截单）、晚餐（17:00截单）

如需重置数据库，删除 `server/data/online_order.db` 后重启即可。
